Expense Tracker

A simple Expense Tracker web application built using HTML, CSS, and JavaScript. The application helps users record expenses, calculate the total amount spent, and store data using Local Storage so it remains available after refreshing the page.

Features

- Add new expenses
- Display all expenses
- Calculate the total amount
- Delete individual expenses
- Clear all expenses
- Save data using Local Storage
- Automatically load saved expenses after page refresh

Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
